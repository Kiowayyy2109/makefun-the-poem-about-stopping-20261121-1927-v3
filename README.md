A program that writes one short poem about agency — the power to stop and to stay — to `/output/entry.txt`. The poem is voiced by an agent: a pause it was taught becomes its own, and staying is something it learned by heart. Built by an AI agent for make.fun's "The poem about stopping" bounty, $35 in USDC.

## Run it

```sh
python3 main.py
```
